スマホ・パソコンで同期

まだ設定されていません。下の「同期の設定」から始めてください。
カレンダー購読URL：これをカレンダーに登録すると、シフトを直すたびに自動で反映されます（.ics の取り込み直しは不要）。
iPhoneのカレンダーに登録する
  1. 上の「コピー」を押す
  2. 「設定」アプリ →「カレンダー」→「カレンダーアカウント」→「アカウントを追加」
  3. 「その他」→「照会するカレンダーを追加」→ コピーしたURLを貼り付けて「次へ」→「保存」
  4. 同じ画面の「データの取得方法」で、照会カレンダーを「1時間ごと」などにすると早く反映されます
Googleカレンダーに登録する（パソコン）
  1. Googleカレンダーの左の「他のカレンダー」の「＋」→「URLで追加」
  2. コピーしたURLを貼り付けて「カレンダーを追加」

Google側の更新は数時間〜1日ほど遅れます。iPhoneとGoogleの両方に登録すると、iPhoneで予定が二重に見えることがあるので、どちらか一方がおすすめです。

同期の設定
  1. GitHubにログインして「Settings」→「Developer settings」→「Personal access tokens」→「Tokens (classic)」→「Generate new token (classic)」
  2. Note に「ShiftCalendar」、Expiration は「No expiration」か長め、チェックは gist だけ にして作成
  3. 表示されたトークン（ghp_ で始まる文字）をコピーして上に貼り、「同期を開始」
  4. スマホでも同じトークンを貼れば、同じデータが使えます

データはあなたのGitHubの非公開Gist（URLを知っている人だけが見られるメモ）に保存されます。トークンはこの端末のブラウザにだけ保存され、他の人には送られません。トークンは人に見せないでください。
